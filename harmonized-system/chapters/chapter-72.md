# Bab 72 — Besi dan Baja

## Lingkup Umum
Bab ini mencakup besi kasar (pig iron), ferro-alloy, produk besi dan baja dalam bentuk primer dan setengah jadi (ingot, bloom, billet, slab), serta produk baja rata (flat-rolled), produk baja panjang (batang, kawat, profil), dan pipa/tabung baja. Bab ini adalah dasar rantai produksi logam besi sebelum menjadi barang jadi (Bab 73).

## Catatan Bab
1. Dalam bab ini, istilah-istilah berikut memiliki arti:
   - (a) **Besi kasar (pig iron)**: paduan besi-karbon dengan kadar karbon > 2% berat, tidak cocok untuk ditempa, digunakan sebagai bahan baku pembuatan baja
   - (b) **Baja** (steel): paduan besi-karbon dengan kadar karbon ≤ 2% berat yang dapat ditempa
   - (c) **Baja tahan karat** (stainless steel): mengandung ≥ 10,5% krom dan ≤ 1,2% karbon
   - (d) **Baja paduan lainnya** (other alloy steel): baja dengan kadar unsur paduan tertentu melebihi batas yang ditetapkan dalam Catatan Bab
   - (e) **Baja non-paduan** (non-alloy steel): baja yang tidak memenuhi definisi baja paduan manapun
2. Bab ini tidak mencakup:
   - (a) Produk-produk dari Bab 73 (barang jadi dari besi atau baja)
   - (b) Logam mulia dan logam mulia berlapis (Bab 71)
   - (c) Rel kereta api dan peralatan konstruksi jalan kereta (Bab 86)
3. Ferro-alloy (ferromangan, ferrosilikon, ferrokrom, dll.) masuk Pos 72.02 — bukan diklasifikasikan sebagai logam murni dari bab logam masing-masing (Mn ke Bab 81, Si ke Bab 28).
4. Produk baja semi-finished (bloom, billet, slab, bramme) masuk Pos 72.06–72.07 untuk baja non-paduan dan pos setara untuk baja paduan.
5. Perbedaan antara **produk rata** (flat-rolled: lembaran, strip, coil) dan **produk panjang** (long products: batang, kawat, profil, rel) sangat penting untuk menentukan pos yang benar.

## Catatan Subpos
1. Dalam subpos yang membedakan baja "hot-rolled" dan "cold-rolled": hot-rolled berarti diproses pada suhu di atas titik rekristalisasi; cold-rolled berarti diproses di bawah titik rekristalisasi — menghasilkan permukaan lebih halus dan toleransi lebih ketat.
2. Untuk Pos 72.08–72.11 (lembaran/coil baja non-paduan), ketebalan dan lebar menjadi penentu subpos.
3. Baja berlapis/dilapisi (galvanis, tin-plate, aluminized) mendapat Pos tersendiri (72.10, 72.12).

## Pengecualian Penting
| Barang | Bab yang Benar |
|--------|----------------|
| Paku, sekrup, baut dari besi/baja | Bab 73 (Pos 73.17–73.18) |
| Pipa besi/baja yang sudah dilengkapi fitting | Bab 73 (Pos 73.04–73.07) |
| Kawat berduri (barbed wire) | Bab 73 (Pos 73.13) |
| Rel kereta api baja | Bab 86 (Pos 86.08) |
| Besi cor (cast iron) barang jadi (kompor, panci besi cor) | Bab 73 (Pos 73.21–73.22) |
| Logam mangan murni | Bab 81 |
| Logam silikon (ferro-grade silicon metal) | Bab 28 (Pos 28.04) |
| Perhiasan dari baja tahan karat | Bab 71 |

## Contoh Klasifikasi
- **Besi kasar (pig iron) tidak dipadukan** → 720110
- **Lembaran baja non-paduan, hot-rolled, dalam gulungan (coil)** → 720840
- **Batang baja non-paduan, hot-rolled** → 721310
- **Baja tahan karat dalam bentuk ingot atau bentuk primer lainnya** → 722410
- **Kawat baja non-paduan berlapis seng (galvanized wire)** → 723090
